## 설명

## Java 예제

입력·처리·결과가 드러나는 작은 Java 예제를 쓴다. 라이브러리나 실행 조건이 필요하면 한 문장으로 적는다.

```java
static int firstIndex(int[] values, int target) {
    for (int i = 0; i < values.length; i++) {
        if (values[i] == target) return i;
    }
    return -1;
}
```

## 주의점

적용 한계와 잘못 이해하기 쉬운 부분을 설명한다.
