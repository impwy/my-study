## 설명

원인과 결과를 짧게 연결한다. 필요하면 표 또는 구체적인 상황을 쓴다.

## 예제

이 섹션은 구현 예제가 필요한 경우에만 넣는다. 알고리즘·자료구조·Java·Spring·JPA·Kafka·Redis 등에서 Java 구현이 도움이 될 때는 아래처럼 작은 코드를 쓴다. 다른 기술은 해당 언어·SQL·셸·YAML을 선택한다. 코드가 불필요하면 섹션 전체를 생략한다. 라이브러리나 실행 조건은 한 문장으로 적는다.

```java
static int firstIndex(int[] values, int target) {
    for (int i = 0; i < values.length; i++) {
        if (values[i] == target) return i;
    }
    return -1;
}
```

## 주의점

적용 한계와 잘못 이해하기 쉬운 부분을 설명한다.

## 꼬리질문

1. 핵심 원리를 설명하는 질문.
2. 첫 질문에서 이어져 구체적인 상황에 적용하는 질문.
3. 전제·경계·트레이드오프를 바꾸어 생각하는 질문.
