# TCP/IP 계층과 라우팅

> 주소·경로·전송·응용 규약의 책임을 나누어 데이터가 상대 애플리케이션까지 가는 흐름을 설명한다.

- IP는 네트워크 간 패킷 전달을 맡는다.
- 전송 계층은 포트로 통신 대상을 구분한다.
- 계층마다 주소·전달 단위가 다르다.

## 설명

같은 링크에서 프레임은 링크 계층 주소로 전달된다. 목적지가 다른 네트워크라면 호스트는 라우팅 테이블에 따라 다음 홉으로 보낸다. 라우터는 IP 목적지와 경로 정보를 이용해 패킷을 전달한다. 수신 호스트의 TCP·UDP는 포트와 연결 정보를 사용해 데이터를 응용 프로그램에 전달한다. 계층 분리는 문제를 주소 해석·경로·전송·응용 처리로 나누어 진단하게 한다.

## 주의점

포트는 호스트 내 전송 종단 식별에 쓰이며 물리 장치 번호가 아니다. NAT는 주소·포트를 바꾸므로 실제 경로 진단에서 별도로 고려한다.

## 꼬리질문

1. 같은 서브넷 통신과 외부 네트워크 통신에서 다음 홉 선택은 어떻게 다른가?
2. 외부 서버에 보낼 때 이더넷 목적지 MAC과 IP 목적지는 각각 누구를 가리킬까?
3. 라우터를 지나면 링크 계층 헤더와 종단 IP 주소는 각각 어떻게 달라질까?
