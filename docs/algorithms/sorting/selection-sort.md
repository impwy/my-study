# 선택 정렬

> 남은 구간의 최솟값을 찾아 현재 자리로 옮긴다.

- 앞 구간은 최종 위치가 확정된다.
- 비교 Θ(n²), 교환 O(n).
- 일반 swap 구현은 안정 정렬이 아니다.

## 설명

매 회차 남은 원소를 전부 비교해 최솟값의 위치를 찾는다. 그 값을 현재 자리와 교환하면 앞 구간은 다시 볼 필요가 없다. 이미 정렬되어 있어도 최솟값을 찾는 비교는 계속한다. 교환은 적지만 비교가 많아서 큰 배열의 일반 정렬에는 적합하지 않다.

## Java 예제

```java
static void sort(int[] a) {
    for (int i = 0; i < a.length - 1; i++) {
        int min = i;
        for (int j = i + 1; j < a.length; j++) if (a[j] < a[min]) min = j;
        int t = a[i];
        a[i] = a[min];
        a[min] = t;
    }
} // [3, 1, 2] → [1, 2, 3]
```

## 주의점

같은 키가 멀리 떨어져 있을 때 swap으로 상대 순서가 뒤집힐 수 있다. “교환이 적다”와 “시간이 빠르다”는 같은 말이 아니다.
