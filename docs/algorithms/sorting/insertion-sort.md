# 삽입 정렬

> 현재 값을 이미 정렬된 앞 구간의 알맞은 위치에 끼운다.

- 앞 구간이 정렬 상태를 유지한다.
- 최악 O(n²), 거의 정렬된 입력에 유리하다.
- 큰 값만 이동시키면 안정적이다.

<details>
<summary>설명과 예제 펼치기</summary>

## 설명

현재 값을 임시로 보관하고 앞 구간에서 더 큰 값들을 오른쪽으로 한 칸씩 민다. 멈춘 자리에 임시 값을 넣으면 앞 구간이 한 칸 확장된다. 이동 비용은 역순 쌍의 개수와 연결된다. 그래서 작은 배열이나 거의 정렬된 배열에서는 단순한 구현이 효과적일 수 있다.

## 예제

[1,4,2]에서 2를 보관하고 4를 오른쪽으로 옮긴 뒤 가운데에 2를 넣어 [1,2,4]를 만든다.

## 주의점

덮어쓰기 전에 현재 값을 저장해야 한다. 같은 값도 밀면 안정성을 잃는다. 최악과 최선의 입력 조건을 함께 말한다.
