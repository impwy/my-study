# 순차 탐색

> 앞에서부터 값을 비교해 목표를 찾거나 모든 후보를 확인한다.

- 정렬 전제가 없다.
- 최악 시간 O(n), 추가 공간 O(1).
- 중복 시 첫 위치·모든 위치 중 목표를 정한다.

<summary>설명과 예제 펼치기</summary>

## 설명

후보를 하나씩 확인하므로 어떤 순서의 배열에도 적용할 수 있다. 목표를 찾으면 즉시 반환하면 첫 일치 위치가 나온다. 전부 확인해야 “없음”을 확정할 수 있어서 실패 탐색의 비용도 선형이다. 데이터가 작거나 한 번만 조회한다면 사전 정렬 비용을 피하는 편이 유리할 수 있다.

## 예제

[7, 2, 7]에서 2를 찾으면 두 번 비교한다. 9를 찾으면 세 원소 모두 확인한다. 첫 7을 찾는 계약이라면 인덱스 0에서 멈춘다.

## 주의점

연결 리스트에 이진 탐색을 그대로 적용해도 중간 노드 접근이 상수 시간이 되지 않는다. 자료 표현과 접근 비용도 함께 본다.
