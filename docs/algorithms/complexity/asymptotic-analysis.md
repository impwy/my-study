# 점근 분석

> 입력 크기가 커질 때 연산 횟수가 어떻게 증가하는지 비교한다.

- 입력 크기 n을 먼저 정의한다.
- 최악·평균·최선은 서로 다른 분석이다.
- 실행 시간 측정과 증가율 분석을 함께 본다.

## 설명

O는 증가율의 상한, Ω는 하한, Θ는 같은 증가율의 상·하한이다. 상수와 낮은 차수 항을 생략해 규모가 커졌을 때의 차이를 드러낸다. 이중 반복문이어도 안쪽 구간이 매번 절반으로 줄면 무조건 O(n²)는 아니다. 각 반복에서 실제로 방문하는 원소 수를 합산한다.

## 예제

n개를 한 번 훑으면 Θ(n), 매 단계 후보를 절반으로 줄이면 Θ(log n)이다. 1+2+…+n번 비교하면 n(n+1)/2이므로 Θ(n²)이다.

## 주의점

O(n)은 “항상 n번”이나 “정확히 n초”라는 뜻이 아니다. JVM 워밍업·입출력·캐시가 실제 측정에 영향을 준다.
