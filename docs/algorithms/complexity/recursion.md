# 재귀와 호출 스택

> 큰 문제를 더 작은 같은 문제에 맡기고 종료 조건에서 돌아온다.

- 종료 조건과 문제 축소가 모두 필요하다.
- 호출마다 지역 상태와 돌아갈 위치를 갖는다.
- 시간 비용과 최대 호출 깊이를 따로 계산한다.

## 설명

재귀를 읽을 때 현재 호출이 맡은 일과 자식 호출에 맡길 일을 분리한다. 반환하면 전체 프로그램이 끝나는 것이 아니라 자신을 호출한 지점 다음으로 돌아간다. 호출이 동시에 살아 있는 깊이만큼 스택 공간을 쓴다. 같은 부분 문제를 반복 호출하는지 확인하면 메모이제이션의 필요성도 보인다.

## 예제

배열 합은 sum(i)=a[i]+sum(i+1), 종료는 i==n일 때 0이다. 원소 n개를 방문하고 최대 n 깊이로 호출되므로 시간 O(n), 스택 O(n)이다.

## 주의점

재귀 이진 탐색의 깊이는 O(log n)이지만 선형 재귀는 O(n)이다. 종료 조건 없는 호출과 너무 깊은 호출을 구분한다.
