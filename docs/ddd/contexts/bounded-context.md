# 바운디드 컨텍스트

> 모델과 용어의 의미 경계, 코드·빌드 경계, 배포 경계를 구분해 업무 책임을 나눈다.

- 같은 이름도 컨텍스트에 따라 다른 의미를 가질 수 있다.
- 경계는 업무 책임·언어·변경 이유를 기준으로 정한다.
- 컨텍스트·Gradle 모듈·배포 서비스는 반드시 일대일이 아니다.

## 설명

결제의 고객은 결제 수단과 청구 정보가, 커뮤니티의 회원은 프로필과 활동 상태가 중요할 수 있다. 같은 회원 ID를 사용해도 서로 다른 모델이 유효하다. 경계 사이에는 공개 계약과 번역 규칙을 두어 상대 모델의 변경이 내부로 그대로 전파되지 않게 한다.

| 경계 | 무엇을 나누는가 |
| --- | --- |
| Bounded Context | 모델과 용어의 의미 |
| Gradle 멀티모듈 | 빌드 단위와 코드 의존성 |
| 모듈형 모노리스 | 하나의 배포 안에서 유지할 책임과 접근 경계 |
| 배포 서비스 | 실행·장애·배포의 단위 |

작은 애플리케이션에서는 코드 모듈로 책임을 먼저 표현할 수 있다. API 실행 앱과 정산 배치 실행 앱을 나누는 것과 결제·정산의 도메인 모델을 나누는 것은 별도 결정이다. Spring Modulith는 애플리케이션 모듈과 노출 인터페이스·의존 관계를 표현하고 구조를 검증할 수 있지만 Gradle 멀티모듈과 동일한 개념은 아니다.

## 멀티모듈·모놀리스·Spring Modulith 비교

| 용어 | 구분 기준 | 다른 개념과의 관계 |
| --- | --- | --- |
| 멀티모듈 | 컴파일·테스트·산출물·의존성을 여러 빌드 단위로 구성 | 한 실행 앱이나 여러 실행 앱으로 조립할 수 있음 |
| 모놀리스 | 하나의 애플리케이션 배포 단위 | 단일 빌드 프로젝트와 멀티모듈 모두 가능 |
| 모듈형 모놀리스 | 하나의 배포 안에 명확한 업무 모듈 경계 유지 | 패키지만으로도, 멀티모듈과 함께도 구성 가능 |
| Spring Modulith | Spring Boot의 논리 모듈을 지원하는 도구 | 모듈 경계 검증과 테스트를 보조하며 배포 단위를 결정하지 않음 |

이 비교는 빌드 문서와 모듈 모델을 연결해 정리한 설계 관점이다. 회원·강의·결제 코드를 각각 Gradle 라이브러리로 만들고 실행 앱 하나에 조립한다면 **멀티모듈로 구현한 모듈형 모놀리스**가 될 수 있다. 파일과 폴더를 나누기만 해서는 업무 경계가 유지되지 않으므로 공개 계약과 데이터 소유권도 정해야 한다.

반대로 단일 Gradle 프로젝트에서 업무 패키지 경계를 유지하며 Spring Modulith를 사용할 수도 있다. 멀티모듈이 곧 마이크로서비스이거나, Spring Modulith가 Gradle 멀티모듈의 대체품이라는 해석은 맞지 않는다. [멀티모듈 구성](../../spring-boot/configuration/multi-module-builds.md)과 [Spring Modulith](../../spring-boot/configuration/spring-modulith.md)를 각각 이어서 읽는다.

## 주의점

모든 컨텍스트를 곧바로 마이크로서비스로 만들지 않는다. 데이터 소유권과 강한 정합성 요구를 먼저 확인한다. 다른 모듈의 테이블을 직접 변경하면 코드 경계가 있어도 책임이 새어 나갈 수 있다. 스키마를 미리 나누어도 물리 DB 분리 후의 트랜잭션·조인·통신·복구 문제는 남는다. [Outbox와 정합성 대사](../../ddia/consistency/outbox-and-reconciliation.md)는 복제·전달을 선택했을 때의 별도 책임이다.

모듈이 같은 JVM과 DB를 사용하더라도 의미·코드·데이터 소유권 경계를 구분한다. 한 물리 DB 안의 스키마 분리는 가능한 선택이며 모듈형 모놀리스의 필수 조건은 아니다. Gradle 의존성이나 Spring Modulith 검사만으로 DB 경계를 전부 강제할 수는 없다.

## 꼬리질문

1. 같은 회원 ID를 공유해도 컨텍스트별 모델이 달라질 수 있는 이유는?
2. 회원·강의 모듈을 실행 앱 하나로 조립하면 의미·빌드·실행 경계를 각각 어떻게 설명할까?
3. 하나의 DB를 물리적으로 분리하면 기존 조인과 트랜잭션의 어떤 가정이 깨질까?
