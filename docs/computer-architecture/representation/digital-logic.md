# 디지털 논리와 상태

> 논리 게이트로 값을 계산하고 순차 회로로 상태를 기억한다.

- 조합 회로는 현재 입력으로 출력이 결정된다.
- 순차 회로는 저장된 상태도 사용한다.
- 진리표와 부울식으로 같은 동작을 표현한다.

<details>
<summary>설명과 예제 펼치기</summary>

## 설명

AND·OR·NOT 같은 연산을 결합해 덧셈·선택·비교를 구현한다. 멀티플렉서는 여러 입력 중 하나를 고르고 디코더는 코드에 맞는 출력을 선택한다. 플립플롭과 레지스터는 상태를 저장해 다음 단계의 입력으로 제공한다. CPU도 계산과 상태 전이가 결합된 회로로 볼 수 있다.

## 예제

한 비트 합은 XOR로, 자리 올림은 AND로 표현할 수 있다. 여러 비트의 덧셈은 아래 자리에서 올라온 carry를 함께 반영한다.

## 주의점

“0과 1”의 논리 의미와 물리 전압을 동일시하지 않는다. 클록·전파 지연 때문에 상태를 저장하는 시점도 중요하다.
