# CPU와 명령어 사이클

> 명령어를 읽고 해석해 연산·메모리 접근·다음 실행 위치를 결정한다.

- PC는 실행 위치를 관리한다.
- 레지스터·ALU·제어 장치의 역할을 구분한다.
- ISA는 하드웨어와 프로그램 사이의 계약이다.

<details>
<summary>설명과 꼬리질문 펼치기</summary>

## 설명

명령어는 연산 코드와 필요한 피연산자 정보로 구성된다. CPU는 PC를 이용해 명령어를 가져오고 제어 신호로 레지스터·ALU·메모리 작업을 연결한다. 분기 명령은 다음 실행 위치를 바꾼다. ISA가 같아도 내부 구현과 성능은 다를 수 있다.

## 주의점

모든 명령어가 같은 클록 수를 쓰지는 않는다. 클록 주파수만으로 실제 프로그램 실행 시간을 비교하지 않는다.

## 꼬리질문

1. 명령어 집합이 같은 두 CPU의 성능이 다른 이유는?
2. 명령을 가져온 뒤 pc를 갱신하지 않으면 어떤 반복이 생길까?
3. 같은 명령어 집합에서도 캐시 미스와 파이프라인 정지가 실행 시간을 바꾸는 이유는 무엇일까?
